# Decor library (жинақ — слайдқа әлі қосылмаған)

Барлығы коммерцияда тегін, авторын көрсетусіз қолдануға болады. Әр папкада `index.json` (файл → тег, лицензия, дереккөз) және `LICENSE.txt`.

| Папка | Не | Саны | Лицензия |
|---|---|---|---|
| `ornaments/` | Қазақ ою-өрнектері: мотив, медальон, бордюр, бұрыш, бөлгіш, жиектеме, плитка (`scripts/build-ornaments.js`) | 46 | өз жұмысымыз |
| `peeps/` | Open Peeps — адамдар (бюст, тұрған, отырған, топ) | 105 | CC0 |
| `doodles/` | Open Doodles — қимылдағы адамдар (оқу, медитация, жүгіру…) | 30 | CC0 |
| `engravings/` | Гравюралар (rawpixel CC0, Cleveland Museum of Art CC0, SMK PD), фоны алынған, DeepSeek-пен іріктеліп тегтелген (en + kk) | 500 | CC0 / PD |
| `../icons/tabler.json`, `../icons/phosphor.json` | белгішелер (Lucide-ке қосымша) | 5184 + 3024 | MIT |

Ескерту: Lucide мен Tabler — viewBox `0 0 24 24` (stroke), Phosphor — `0 0 256 256` (regular: stroke; `-duotone`: fill + opacity).
Ою-өрнектер `currentColor` арқылы боялады.
